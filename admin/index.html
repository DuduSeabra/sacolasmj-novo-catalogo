Configurar acesso

Informe suas credenciais do GitHub para poder salvar alterações de preço diretamente no repositório.

O token fica salvo somente neste navegador (localStorage). Nunca compartilhe esta página logada.
Crie em GitHub → Settings → Developer settings → Personal access tokens (Classic). Escopo necessário: repo (ou apenas contents:write).
Edite os preços abaixo e clique em Salvar alterações. O site atualiza automaticamente em ~30 segundos após o commit.
